🌐 이 프로그램을 GitHub Pages에 올리는 방법

        
      

      
    
        
  1. 상단 💻 GitHub 업로드용 코드 탭에서 index.html 파일로 다운로드를 클릭하거나 전체 코드를 복사해 내 컴퓨터에 index.html로 저장합니다.
    2. 
        
  2. GitHub에서 새 Public 저장소(예: pill-counter 또는 아이디.github.io)를 생성합니다.
    3. 
        
  3. 저장소 화면에서 Add file → Upload files를 눌러 index.html을 올리고 Commit changes를 클릭합니다 (또는 VS Code에서 Push).
    4. 
        
  4. 저장소의 Settings → Pages 메뉴에서 Branch를 main으로 설정하고 Save를 누르면 1~2분 뒤 약국 스마트폰·태블릿·PC 어디서나 접속 가능한 웹 주소가 생성됩니다!
    5.
